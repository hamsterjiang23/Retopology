# 重拓扑跨方法横评 2026-08-13

## 结论先行

本轮所有可执行路线都使用同一个 Meshy「幽灵乐手」高模，分别做 raw robustness 与 controlled quality 两条线。原生 QuadriFlow、Instant Meshes、既有基线都进入统一指标；AutoRemesher、Blender QuadriFlow、NeurCross、MeshAnything V2、LATO.2 也实际启动过，失败保留退出码、日志和环境原因。

- 当前最稳定的四边面生产组是原生 QuadriFlow 与 Instant Meshes：两者在 raw/controlled × low/medium 四格均成功，输出 OBJ 的 quad ratio 为 1.0。
- controlled 输入通常比 raw 输入更接近高模、组件更少，但两种方法都没有保证 watertight；复杂输入的组件碎裂仍需人工检查。
- Blender 4.5.11 的 QuadriFlow operator 四格均失败，而同一算法的原生 CLI 四格成功。这说明入口前置条件与实现包装会影响结果，不能把 Blender 失败写成 QuadriFlow 算法失败。
- AutoRemesher 官方 1.0.0 CLI 可以跑通小型 demo，但对本模型 raw 发生 Windows access violation（`-1073741819`），controlled 以 code 1 退出，不能用既有 Manifold→AutoRemesher 成品替代本轮直跑。
- MeshAnything V2 在 Mac Studio 已加载本地权重并进入生成阶段；raw 与 controlled 的 MPS/CPU fallback 均在约 7 分钟后以 code 137 终止。它是资源阻塞，不是未部署。
- NeurCross 的 controlled 单迭代在 MPS 上完成了 cross-field 优化；raw 在旋转矩阵预计算阶段因非流形邻接 `KeyError` 失败。官方仓库没有把 cross-field 训练自动接成最终 mesh extraction，因此不进入几何 SUCCESS。
- LATO.2 权重已下载，但官方入口在 Mac 卡在 TRELLIS.2 的 `o_voxel` 自定义 CUDA 扩展；MeshFlow 权重受 Hugging Face gated model 权限限制（Windows 401、Mac 403）。

## 未进入自动分数的论文路线

- SATO：公开的是 NumPy tokenizer，能做 triangle/quad strip 序列化和反序列化，但不是完整生成模型；官方 demo 单测 17/17 通过，full Meshy raw/controlled tokenizer smoke 在四分钟、约 2.1GB RAM 后无输出而停止。
- MeshMosaic：官方仓库存在，但 README 明确把预训练 checkpoint、inference、预处理、训练列为发布清单；不能把项目页展示当成本地结果。
- QuadGPT：论文提出 native quad autoregressive + tDPO；项目页提供论文/演示入口，本轮没有可下载的官方本地推理仓库或 checkpoint。
- SQuadGen：项目页的 Code 标为 “coming soon”；其核心是 Chart Distance Field、扩散布局生成与 loop simplicity 指标。
- QuadLink：论文提出 anchor/centroid-conditioned linking 和 quad-first assembly；本轮没有官方可运行仓库。
- TriFlow：项目页的 Code 标为 TBA；其路线是 SDF→nearest-vertex vector field→watershed/QEM extraction，属于 artist-like triangle generation，不与 quad-remeshing 混分。

## 发展脉络与方法分层

1. 几何修复与体素/减面：先处理非流形、孔洞、重复面，再用 OpenVDB、fast-simplification 等建立可控基线。
2. 场/方向场四边化：QuadriFlow、Instant Meshes、QuadWild 通过方向场、奇点和全局/局部优化得到 quad layout；优点是几何约束明确，缺点是对脏输入、非流形和尖锐特征敏感。
3. 面向生产的自动工具：AutoRemesher 等把各向同性重网格、参数化和 quad extraction 组合成工具链；对复杂扫描资产仍要把失败和前置清理纳入评估。
4. 自回归 artist-like mesh：MeshAnything V2、MeshFlow、LATO.2 直接学习顶点/面序列或 vertex/topology flow，面数预算更低，但输出可能改变组件、孔洞、语义和原始几何。
5. 结构化生成拓扑：SATO 用 strips/UV transitions，MeshMosaic 用 boundary-conditioned local-to-global patches，QuadGPT 用 native mixed-topology tokens + tDPO，QuadLink 用 point-relation linking，SQuadGen 用 CDF，TriFlow 用 NVF。共同趋势是把“拓扑”从后处理提升为生成目标，但代码/权重发布仍滞后于论文。

## 生产建议

- 静态资产：light cleanup → CGAL/Manifold 修复 → 原生 QuadriFlow 或 Instant Meshes → 统一 UV → 从高模回烘 Normal/AO/PBR → LOD。
- 角色、面部和关节：自动四边化只当 base topology，随后用 RetopoFlow/Quad Draw 人工修正语义环线。
- 低面 artist-like：把 MeshAnything V2、MeshFlow、LATO.2 作为独立生成组，额外检查轮廓、组件、孔洞和语义丢失；不能用 quad ratio 单指标判优。
- 研究复现：优先申请 MeshFlow gated checkpoint；其次解决 LATO.2 的 CUDA extension；NeurCross 需要把 cross-field 输出接到可验证的 extraction；QuadWild 需要 Gurobi 或替代 ILP 后端。
